# Конспект — Telegram Mini App

Навчальний застосунок для однієї студентки ветеринарної медицини: робоча
програма, розклад пар, конспекти, картки з інтервальним повторенням, тести
й домашнє завдання.

Сторінка статична. Усе, що вона показує, лежить у `data/`; прогрес повторень
зберігається в самому телефоні (`localStorage`). Ні сервера, ні API, ні ключів.

## Оновити зміст

Матеріал готується в основному репозиторії проєкту і копіюється сюди
скриптом `miniapp/build.sh`, після чого папка викладається як є.
